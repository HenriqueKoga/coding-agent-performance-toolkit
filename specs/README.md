# Specs

Spec Kit feature directories live here. They are specification artifacts, not CAPT runtime code.

A Spec Agent produces these directories with this repository's pinned Spec Kit workflow and project-local templates. See [docs/spec-kit.md](../docs/spec-kit.md) for the authoring contract and [`.specify/memory/constitution.md`](../.specify/memory/constitution.md) for principles.

The first pilot is [001-compaction-pressure](001-compaction-pressure/). It demonstrates `specify → plan → tasks → analyze` for a future insight. It does not implement that insight.
